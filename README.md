# SecureAuth
An Android authentication app built with Kotlin, Room Database, Coroutines, and BCrypt password hashing. Implements user registration and login with locally stored credentials.

Features
    - User registration with username and password.
    - User login with credential validation.
    - Local data persistence using Room Database.
    - Password hashing using BCrypt.
    - Asynchronous database operations using Kotlin Coroutines.
    - XML-based user interface with View Binding.

Tech Stack
    - Language: Kotlin
    - Platform: Android
    - Database: Room
    - Asynchronous operations: Kotlin Coroutines
    - Password hashing: jBCrypt
    - UI: XML layouts and View Binding
    - Build system: Gradle with Kotlin DSL
    - Annotation processing: KSP
